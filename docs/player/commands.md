# Liber Terra Commands

| Command | Description |
| ------- | ----------- |
| `/liberterra list` | List volumes |
| `/liberterra give <code>` | Give a complete volume (e.g. `beowulf`, `songofroland-vol1`) |
| `/liberterra giveall <baseCode>` | Give every volume of a work (e.g. `songofroland`) |
